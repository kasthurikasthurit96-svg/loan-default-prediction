**Loan Default Prediction System using Python**

## Project Description

The Loan Default Prediction System is a data analysis and machine learning project developed using Python. 
The project analyzes loan applicant data to understand factors affecting loan defaults and predicts loan amounts using Linear Regression.

**This project includes:**

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Visualization using Matplotlib, Seaborn, and Plotly
* Risk classification
* Linear Regression model
* Model evaluation metrics



## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Scikit-learn
* Google Colab



## Features

* Load and analyze loan dataset
* Handle missing values
* Perform statistical analysis
* Visualize loan patterns and relationships
* Analyze loan default behavior
* Risk level classification
* Build Linear Regression model
* Evaluate model performance
* Interactive dashboards using Plotly



## Dataset Columns Used

* LoanAmount
* LoanTerm
* InterestRate
* Income
* MonthsEmployed
* HasMortgage
* LoanPurpose
* Default



## Machine Learning Model

### Linear Regression

The model predicts loan amount based on:

* Income
* Interest Rate
* Loan Term

### Evaluation Metrics

* R2 Score
* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)



## Visualizations Included

* Count Plot
* Scatter Plot
* Histogram
* Box Plot
* Correlation Heatmap
* Residual Plot
* Interactive Plotly Charts



## Risk Classification

Interest rates are categorized into:

* Low Risk
* Medium Risk
* High Risk



## How to Run the Project

### Step 1: Install Required Libraries

```python
pip install pandas numpy matplotlib seaborn plotly scikit-learn
```

### Step 2: Upload Dataset

Place the dataset file:

```python
Loan_default.csv
```

### Step 3: Run the Python File

```python
python loan_default_prediction.py
```
